# 데스로드 투 캐나다 한글패치 (비공식)

스팀판 Death Road to Canada의 대사와 메뉴를 한글로 바꿔 드리는, 본 영애가 직접 엮은 팬패치인 것이와요.

컴퓨터를 잘 모르는 영식, 공녀라도 걱정하실 것 없사와요. 아래를 **위에서부터 순서대로** 따라 하기만 하면 된답니다. 중간에 하나라도 건너뛰시면 거의 틀림없이 실패하니, 차를 한 잔 곁들이며 천천히 진행하시와요.

**어떻게 돌아가는 것이냐 하면**
여기에는 번역문과 설치 프로그램만 들어 있는 것이와요. 게임 파일은 저작권 때문에 올릴 수 없었답니다.
설치를 돌리면 그대 컴퓨터에 깔린 영어판을 읽어 그 자리에서 한글판을 빚어내 깔아 드리는 방식이랍니다. 그러니 스팀 정품은 반드시 갖추고 계셔야 마땅하답니다.
깔기 전에 게임 폴더를 통째로 백업해 두니, 마음에 들지 않으시면 언제든 원래대로 되돌릴 수 있사와요. 제가 그 정도 배려도 없이 일을 벌일 리 없지 않겠사와요?

---

## 0. 시작하기 전에 확인하실 것

- **윈도우**에서만 된답니다. 맥, 리눅스, 스팀덱은 아쉽게도 모시지 못하는 것이와요
- **스팀 정품**이어야 한답니다
- 게임이 **최신 버전**이고 **다른 모드가 깔려 있지 않아야** 하는 것이와요
  - 지원하는 빌드는 `24936165` 단 하나뿐이랍니다
  - 버전이 다르거나 다른 모드가 파일을 건드려 놓았다면 설치 프로그램이 알아서 멈춘답니다. 게임이 망가질 일은 없으니 그렇게 겁먹으실 필요 없사와요
- 예전에 이 패치를 깐 적이 있으시다면 [6번 삭제](#6-삭제하는-법)부터 마치고 오시와요

---

## 1. 파이썬 깔기

설치 프로그램은 파이썬이라는 것으로 돌아간답니다. 한 번만 깔아 두면 그만인 것이와요.

1. [python.org](https://www.python.org/downloads/windows/)에서 3.10 이상이면 아무것이나 받으시와요. 고민되시면 가장 최신 것을 고르시면 된답니다
2. 설치 파일을 켜면 첫 화면 아래쪽에 **`Add python.exe to PATH`** 체크박스가 있사와요
   - **이것을 체크하지 않으면 뒤에서 반드시 막힌답니다. 본 영애가 두 번 말하게 하지 마시와요**
3. `Install Now`를 누르고 기다리면 끝이랍니다

이미 깔려 있는지 모르시겠다면 그냥 한 번 더 까셔도 아무 문제 없사와요.

---

## 2. 한글패치 받기

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼 → **`Download ZIP`**을 누르시와요
2. 받은 zip 파일을 오른쪽 클릭 → **압축 풀기**를 하시와요
3. 풀린 폴더는 찾기 쉬운 곳에 두도록 하시와요. `C:\DRTC-KO` 같은 곳이 좋답니다
   - **게임 폴더 안에 넣는 것은 허락하지 않겠사와요**

이것이 앞으로 말씀드릴 **패치 폴더**랍니다. 열었을 때 `install.py` 같은 파일이 보이면 제대로 찾으신 것이와요.

---

## 3. 모드 로더 받기

한글을 화면에 띄우려면 **모드 로더**가 따로 필요한 것이와요. 이것은 일본어 패치를 만드신 분의 배포본인데 재배포가 금지되어 있어서 여기에 함께 넣어 드릴 수 없었답니다. 번거로우시겠지만 직접 받아 오시와요.

1. [ハム님 일본어 패치 배포 페이지](https://arkwright1.blog.fc2.com/blog-entry-1576.html)에서 **V202.0**을 받으시와요
2. **게임 폴더가 아닌 다른 곳**에 풀어 두시와요. `C:\DRTC-Loader` 같은 곳이면 충분하답니다
   - 실행하면 압축이 풀리는 파일이라면 그냥 실행하고, 풀 위치만 게임 폴더 바깥으로 잡아 주시면 된답니다
3. 풀린 것 가운데 **`1.MOD LOADER`** 폴더를 찾으시와요
   - 열었을 때 `dr2c-gadget.dll`과 `mods` 폴더가 **바로** 보여야 한답니다
   - 이것이 **로더 폴더**인 것이와요

**배포본 안의 `prog_Patch.exe`는 절대로 실행하지 마시와요.** 그 일은 이 설치 프로그램이 대신 해 드린답니다. 멋대로 실행하셨다가는 설치가 되지 않으니 각오하시와요.
로더 폴더 안의 파일도 손대지 말고 받은 그대로 두시와요. 하나라도 바뀌면 설치가 멈춘답니다.

---

## 4. 게임 폴더 찾기

1. 스팀 → 라이브러리로 가시와요
2. Death Road to Canada를 오른쪽 클릭 → **관리** → **로컬 파일 보기**를 누르시와요
3. 열린 폴더에 `prog.exe`가 있다면 그곳이 바로 **게임 폴더**랍니다

보통은 이런 경로인 것이와요.

```
C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada
```

### 경로 복사하는 법 (중요하답니다)

경로를 손으로 치다가는 오타가 나기 마련이랍니다. 복사해서 쓰시와요.

- 폴더를 **Shift를 누른 채로 오른쪽 클릭** → **`경로로 복사`**를 누르시와요
- 그러면 `"C:\...\Death Road to Canada"`처럼 **양쪽 큰따옴표까지 함께 복사된답니다.** 그대로 붙여넣으시면 되는 것이와요

메모장을 하나 열어 게임 폴더와 로더 폴더 경로를 미리 붙여 두시면 한결 편하답니다.

---

## 5. 설치

**게임은 꺼 두시와요.** 켜져 있으면 깔리지 않는답니다.

### 5-1. 명령창 열기

1. 탐색기로 **패치 폴더**에 들어가시와요
2. 위쪽 주소창(경로가 나오는 곳)을 클릭해 내용을 지우고 `powershell`이라고 친 다음 엔터를 누르시와요
3. 파란 창이 뜨면 성공이랍니다. 여기에 아래 명령어를 하나씩 붙여넣고 엔터를 누르시면 되는 것이와요

붙여넣기는 Ctrl+V나 마우스 오른쪽 클릭이랍니다.

### 5-2. 필요한 부품 설치 (처음 한 번만)

```powershell
python -m pip install -r requirements.txt
```

글자가 쭉 올라가다가 `Successfully installed` 어쩌고가 뜨면 된답니다.
`Requirement already satisfied`가 떠도 이미 깔려 있다는 뜻이니 괜찮사와요.

### 5-3. 시험 설치 (게임은 건드리지 않는답니다)

진짜로 깔기 전에 문제가 없는지 미리 돌려 보는 단계인 것이와요. **게임 파일은 하나도 바뀌지 않으니** 마음 놓고 돌리시와요.

아래 명령어를 메모장에 복사한 뒤, `"게임 폴더"`와 `"로더 폴더"` 부분을 4번에서 복사해 둔 경로로 **따옴표째** 바꿔 넣으시와요.

```powershell
python install.py --game-root "게임 폴더" --loader-root "로더 폴더" --check
```

바꾸고 나면 대략 이런 모양이 된답니다.

```powershell
python install.py --game-root "C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada" --loader-root "C:\DRTC-Loader\1.MOD LOADER" --check
```

이 한 줄을 통째로 명령창에 붙여넣고 엔터를 누르시와요. 시간이 조금 걸릴 수 있으니 재촉하지 말고 기다리시와요.

- `{ "mode": "install", ... }` 같은 것이 쭉 뜨면 **성공**이랍니다. 다음 단계로 넘어가시와요
- 빨간 글씨로 `ERROR: ...`가 뜨면 **실패**인 것이와요. [7번 오류 모음](#7-오류가-뜨면)을 살펴보시와요

### 5-4. 진짜 설치

방금 쓴 명령어에서 **맨 끝의 `--check`만 `--apply`로 바꿔** 다시 돌리시면 끝이랍니다.

```powershell
python install.py --game-root "C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada" --loader-root "C:\DRTC-Loader\1.MOD LOADER" --apply
```

- 깔기 전에 게임 폴더를 통째로 **백업**한답니다. 게임 폴더 옆에 `Death Road to Canada_KO_backup_날짜` 같은 이름으로 생기는 것이와요
- 통째로 복사하는 일이라 **시간이 좀 걸리고 그만큼 용량도 차지한답니다**
- 끝난 뒤 `ERROR`가 없다면 설치가 완료된 것이와요

이제 스팀에서 평소처럼 게임을 켜시면 한글로 나온답니다. 본 영애의 솜씨에 감탄하셔도 좋사와요.

백업 위치를 직접 정하고 싶으시다면 `--apply` 앞에 `--backup-root "새 폴더 경로"`를 넣으시와요. 다만 그 폴더는 **아직 존재하지 않는 새 폴더**여야 한답니다.

**백업 폴더는 지우지 마시와요.** 나중에 패치를 지울 때 이것으로 원래대로 되돌리는 것이와요.

---

## 6. 삭제하는 법

영어판으로 돌아가고 싶으시다면 **게임을 끄고** 5-1처럼 패치 폴더에서 명령창을 여시와요.

먼저 검사부터 하시와요. 아무것도 바뀌지 않는답니다.

```powershell
python uninstall.py --game-root "게임 폴더" --check
```

문제가 없다면 진짜로 지우시와요.

```powershell
python uninstall.py --game-root "게임 폴더" --apply
```

- 패치가 바꾼 파일은 백업에서 원래대로 되돌리고, 패치가 추가한 파일만 지운답니다
- 다 끝나도 백업 폴더는 남아 있사와요. 영어로 잘 나오는 것을 확인한 뒤에 지우셔도 늦지 않는답니다
- 패치 파일을 직접 건드리셨거나 백업이 망가져 있다면 안전을 위해 중간에 멈추는 것이와요

## 7. 오류가 뜨면

| 이것이 뜬다면 | 이렇게 하시와요 |
|---|---|
| `python`은(는) 인식할 수 없는... / MS 스토어가 열림 | 파이썬을 깔 때 `Add python.exe to PATH`를 체크하지 않으신 것이와요. 그토록 일렀건만! 설치 파일을 다시 켜서 Modify/Repair를 하시거나, 지우고 체크한 뒤 다시 까시와요. 그래도 안 되면 명령어 앞의 `python`을 `py`로 바꿔 보시와요 |
| `No module named 'polib'` 또는 `'PIL'` | 5-2를 건너뛰셨거나 실패한 것이와요. 다시 해 보시와요 |
| `The target game is running` / `close it first` | 게임이 켜져 있는 것이와요. 완전히 끄고 다시 하시와요 |
| `Game root must be the folder containing prog.exe` | 게임 폴더 경로가 틀린 것이와요. `prog.exe`가 바로 들어 있는 폴더인지 확인하시와요 (4번) |
| `Unsupported prog.exe SHA-256` | 게임 버전이 다르거나, `prog_Patch.exe`를 이미 실행하셨거나, 다른 모드가 건드린 것이와요. 스팀에서 게임 오른쪽 클릭 → 속성 → 설치된 파일 → **게임 파일 무결성 검사**를 하고 다시 해 보시와요. 그래도 안 된다면 스팀 업데이트로 버전이 바뀐 것이니 패치가 갱신될 때까지 기다려 주시와요 |
| `Unsupported/modified English script` | 게임 파일이 원래 상태가 아닌 것이와요. 위처럼 무결성 검사를 하시와요 |
| `Loader SHA-256 mismatch or missing file` | 로더 폴더를 잘못 잡으셨거나 버전이 다른 것이와요. `dr2c-gadget.dll`이 **바로** 들어 있는 `1.MOD LOADER` 폴더인지, V202.0이 맞는지 확인하시와요 (3번) |
| `Download the loader into a separate folder outside the game` | 로더 폴더가 게임 폴더 안에 있는 것이와요. 바깥으로 옮기시와요 |
| `Remove the existing Korean patch...` / `An installation record ... already exists` | 이미 깔려 있는 것이와요. 6번으로 지우고 다시 까시와요 |
| `Backup root must be a new, nonexistent folder` | `--backup-root`로 잡은 폴더가 이미 있는 것이와요. 없는 이름으로 바꾸시와요 |
| `No Korean patch installation record` (삭제할 때) | 이 게임 폴더에는 패치가 깔려 있지 않은 것이와요. 경로가 맞는지 확인하시와요 |
| `This installer requires Windows` | 윈도우에서만 된답니다. 이것만큼은 저도 어쩔 도리가 없사와요 |

여기 없는 오류가 뜬다면 [Issues](../../issues)에 빨간 `ERROR:` 줄을 복사해 올려 주시와요.
다만 오류에 그대 컴퓨터의 사용자 이름 같은 것이 찍혀 있다면 그 부분은 가리고 올리시와요.

## 8. 알려진 문제

- `은(는)`, `이(가)`처럼 나오는 곳이 있사와요. 캐릭터 이름이 무작위로 들어가는 탓이라 저로서도 어쩔 수 없었답니다
- 캐릭터 이름과 특성 이름 같은 것은 일부러 영어로 두었사와요. 게임이 이것으로 내부 판정을 하는지라, 번역했다가는 게임이 꼬이는 것이와요
- 캐릭터 이름을 한글로 입력하는 것은 아직 제대로 시험해 보지 못했답니다
- 처음부터 엔딩까지 한 판을 다 돌려 본 것은 아니라서, 이상한 곳이 보이면 제보해 주시와요. 결코 본 영애가 게을러서가 아니랍니다

오역이나 어색한 문장이 보인다면 [Issues](../../issues)에 올려 주시와요. **어느 장면(이벤트)에서 나왔는지** 함께 적어 주시면 찾기가 훨씬 수월하답니다.

### 어디에도 올려서는 아니 되는 것

- 게임 파일, 백업 폴더, 모드 로더 배포본 (저작권 문제랍니다)
- 설치 기록 파일(`.drtc_ko_install.json`)이나 백업 안의 기록 파일. 그대 컴퓨터의 폴더 경로가 고스란히 담겨 있는 것이와요

### 번역 파일

- `translations/001.po` ~ `033.po`가 대사, `native-ko.po`가 UI 번역이랍니다
- `msgctxt`는 게임 안의 파일 경로인 것이와요
- 비어 있는 번역과 fuzzy는 영어로 나오고, `<EMPTY>`는 빈 문자열로 바뀐답니다
- 게임이 비교용으로 쓰는 문자열(캐릭터 이름, 특성 이름 등)과 native UI 키는 일부러 영어로 두었사와요
- 빌드할 때 자리표시자, 제어문자, 줄바꿈, 조사 조각, 폰트에 없는 글자까지 전부 검사한답니다

PR은 언제든 너그럽게 받아 드리겠사와요.

### 설치 없이 한글 모드만 만들어 보기

새 폴더를 지정해 돌리시면 된답니다. 게임/로더/패치 폴더와 겹쳐서는 아니 되는 것이와요.

```powershell
python build_ko.py --game-root "<게임 폴더>" --loader-root "<로더 폴더>" --output "<생성 폴더>"
```

### 설치 방식

- PC에 있는 영어 `.df` 스크립트의 해시를 검증하고, 그것으로 한글판을 그 자리에서 생성한답니다
- 원래 `deathforth/` 파일은 그대로 두고 `mods/DRTC_KO/`가 위에 덮어씌워지는 방식인 것이와요
- 로더 배포본에서는 검증된 파일 8개만 읽어 가고, 일본어 대사나 `prog_Patch.exe`는 건드리지 않는답니다. `prog.exe` 패치는 설치 프로그램이 직접 하는 것이와요 (pefile은 `vendor/`에 포함)
- `--check`는 임시 폴더에서 빌드와 설치 검증만 하고, `--apply`는 게임 폴더 전체를 백업하고 해시를 확인한 다음 설치한답니다
- 로더 원본 프로젝트는 [sevenshape/dr2c-mod-loader](https://github.com/sevenshape/dr2c-mod-loader)랍니다. 옛날 `SDL2_mixer.dll` 프록시 방식과는 호환되지 않사와요

### 폰트

`fonts/hangul_12x12.png`는 Galmuri11로 만든 한글 전용 투명 오버레이랍니다.
설치할 때 로더 폰트 아틀라스의 한글 칸(U+AC00–D7A3, U+3131–318E)에만 합쳐지고, 다른 글자와 아이콘은 그대로인 것이와요. 12×12 비트맵 폰트이며 완성형 한글과 호환 자모가 모두 나온답니다. 다시 만들고 싶으시다면 이렇게 하시와요.

```powershell
python make_hangul_atlas.py --bdf fonts/Galmuri11.bdf --output "<새 오버레이 PNG>"
```

생성된 `.df`, 게임 실행 파일, 백업, 로더 배포본은 공개 저장소에 올리지 마시와요.
