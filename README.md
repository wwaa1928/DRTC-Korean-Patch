# 데스로드 투 캐나다 한글패치 (비공식)

스팀판 Death Road to Canada의 대사와 메뉴를 한글로 바꿔 드리는 팬패치랍니다. 좀비에게 쫓기는 와중에 영어까지 붙들고 계실 그대를 위해 본 영애가 손수 엮었사와요. 이 정도 배려라면 감사히 받아 가셔도 좋사와요. (만든 이: **wwaa1928**, **wwwwwwwoooo** · 무단 재배포와 사칭은 금지랍니다. [저작권](#저작권)을 보시와요)

컴퓨터에 서툰 영식, 공녀라도 기죽으실 필요 없사와요. 그대가 헤매지 않도록 순서까지 챙겨 두었으니, 아래를 **위에서부터 순서대로** 따라 하시와요. 혼자 짐작해서 단계를 건너뛰는 솜씨는 본 영애 앞에서 뽐내지 않으셔도 된답니다.

**설치 원리도 짚어 드리겠사와요**
여기에는 번역문과 설치 프로그램만 들어 있답니다. 게임 파일은 저작권 때문에 함께 올릴 수 없사와요.
설치 프로그램이 그대 컴퓨터에 깔린 영어판을 읽고, 그 자리에서 한글판을 만들어 설치하는 방식인 것이와요. 그러니 스팀 정품은 반드시 갖추고 계셔야 마땅하답니다.
설치 전에는 게임 폴더를 통째로 백업하니, 마음에 들지 않으시면 원래대로 되돌릴 수도 있답니다. 본 영애가 솜씨만 뽐내고 뒷일은 나 몰라라 할 줄 아셨사와요?

---

## 0. 시작하기 전에 확인하실 것

- **윈도우**와 **스팀덱·리눅스**(Proton)에서 쓸 수 있답니다. 다만 스팀덱·리눅스 쪽은 아직 실험 단계이고, 맥은 지원하지 못한답니다. 모두 챙겨 드리고 싶어도 의욕만으로 될 일은 아니었사와요
  - 스팀덱이나 리눅스라면 아래 1~5번 대신 [스팀덱과 리눅스에서 깔기](#스팀덱과-리눅스에서-깔기-실험적)를 따르시와요
- **스팀 정품**이어야 한답니다
- 게임이 **최신 버전**이고 **다른 모드가 깔려 있지 않아야** 하는 것이와요
  - 지원하는 빌드는 `24936165` 단 하나뿐이랍니다
  - 버전이 다르거나 다른 모드가 파일을 건드려 놓았다면 설치 프로그램이 멈춘답니다. 맞지 않는 파일에 억지로 설치하지 않도록 해 둔 것이니, 오류가 떴다고 덜컥 겁부터 먹지 마시와요
- 예전에 이 패치를 깐 적이 있으시다면 [6번 삭제](#6-삭제하는-법)부터 마치고 오시와요. 두 번 덮는다고 두 배로 한글이 되는 것은 아니랍니다

## 1. 파이썬 깔기

설치 프로그램을 돌리려면 파이썬이 필요하답니다. 이름부터 낯설다고 뒷걸음치지 마시와요. 한 번만 깔아 두면 그만인 것이와요.

1. [python.org](https://www.python.org/downloads/windows/)에서 3.10 이상이면 아무것이나 받으시와요. 고르기 어려우시면 가장 최신 것으로 하시와요
2. 설치 파일을 켜면 첫 화면 아래쪽의 **`Add python.exe to PATH`** 체크박스에 체크하시와요
   - **이것을 빼먹으면 뒤에서 파이썬을 찾지 못할 수 있답니다. 작은 네모 하나 때문에 본 영애를 두 번 부르는 일은 없도록 하시와요**
3. `Install Now`를 누르고 기다리시면 끝이랍니다

이미 깔려 있는지 기억나지 않으신다면 설치 파일을 한 번 더 실행하셔도 괜찮사와요. 기억을 더듬느라 여기서부터 진을 빼실 필요는 없답니다.

---

## 2. 한글패치 받기

1. 이 페이지 위쪽의 초록색 **`<> Code`** 버튼 → **`Download ZIP`을** 누르시와요
2. 받은 zip 파일을 오른쪽 클릭 → **압축 풀기**를 하시와요
3. 풀린 폴더는 찾기 쉬운 곳에 두시와요. `C:\DRTC-KO` 같은 곳이 좋답니다
   - **게임 폴더 안에 넣는 것은 허락하지 않겠사와요. 나중에 두 폴더를 헷갈릴 빌미부터 없애 두시와요**

이것이 앞으로 말씀드릴 **패치 폴더**랍니다. 열었을 때 `install.py`가 보인다면 제대로 찾으신 것이와요. 앞으로 자주 부를 이름이니 눈여겨 두시와요.

---

## 3. 모드 로더 받기

한글을 화면에 띄우려면 **모드 로더**가 따로 필요하답니다. 일본어 패치를 만드신 분의 배포본은 재배포가 금지되어 있어 함께 넣어 드릴 수 없사와요. 한 번에 챙겨 드리지 못하는 것은 저도 아쉽지만, 남의 배포 규칙까지 제 뜻대로 할 수는 없는 법이랍니다. 아래에서 직접 받아 오시와요.

1. [ハム님 일본어 패치 배포 페이지](https://arkwright1.blog.fc2.com/blog-entry-1576.html)에서 **V202.0**을 받으시와요
2. **게임 폴더가 아닌 다른 곳**에 풀어 두시와요. `C:\DRTC-Loader` 같은 곳이면 충분하답니다
   - 실행하면 압축이 풀리는 파일이라면 그냥 실행하시되, 풀 위치만 게임 폴더 바깥으로 잡아 주시와요
3. 풀린 것 가운데 **`1.MOD LOADER`** 폴더를 찾으시와요
   - 열었을 때 `dr2c-gadget.dll`과 `mods` 폴더가 **바로** 보여야 한답니다
   - 이것이 **로더 폴더**랍니다

**배포본 안의 `prog_Patch.exe`는 절대로 실행하지 마시와요.** 실행 파일을 바꾸는 일은 이 설치 프로그램이 맡는답니다. 이름에 패치가 붙었다고 덥석 누르는 성급함은 잠시 거두시와요. 먼저 실행해 버리시면 이 한글패치는 설치할 수 없게 되는 것이와요.
로더 폴더 안의 파일도 받은 그대로 두시와요. 하나라도 바뀌면 검증에서 멈추니, 정리해 드리겠다는 친절도 이번에는 사양하겠사와요.

---

## 4. 게임 폴더 찾기

1. 스팀 → 라이브러리로 들어가시와요
2. Death Road to Canada를 오른쪽 클릭 → **관리** → **로컬 파일 보기**를 누르시와요
3. 열린 폴더에 `prog.exe`가 있다면 그곳이 바로 **게임 폴더**랍니다

보통은 이런 경로랍니다.

```
C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada
```

### 경로 복사하는 법 (중요하답니다)

긴 경로를 손으로 치다가 철자 하나 틀리는 일은 흔하답니다. 그대의 타자 실력을 의심해서가 아니라… 크흠, 아무튼 복사해서 쓰시와요.

- 폴더를 **Shift를 누른 채로 오른쪽 클릭** → **`경로로 복사`를** 누르시와요
- 그러면 `"C:\...\Death Road to Canada"`처럼 **양쪽 큰따옴표까지 함께 복사된답니다.** 따옴표도 필요하니 떼어 내지 말고 그대로 붙여넣으시와요

메모장에 게임 폴더와 로더 폴더 경로를 미리 붙여 두시와요. 필요할 때마다 폴더 사이를 헤매실 수고를 덜어 드리려는 본 영애의 배려랍니다.

## 5. 설치

**게임부터 완전히 꺼 두시와요.** 켜 둔 채 설치까지 해 달라는 욕심은 허락하지 않겠사와요.

### 5-1. 명령창 열기

1. 탐색기로 **패치 폴더**에 들어가시와요
2. 위쪽 주소창(경로가 나오는 곳)을 클릭해 내용을 지우고, `powershell`이라고 친 다음 엔터를 누르시와요
3. 명령창이 열리면 성공이랍니다. 아래 명령어를 하나씩 붙여넣고 엔터를 누르시와요. 낯선 창이라고 주눅 드실 것 없사와요

붙여넣기는 Ctrl+V나 마우스 오른쪽 클릭이랍니다.

### 5-2. 필요한 부품 설치 (처음 한 번만)

```powershell
python -m pip install -r requirements.txt
```

글자가 쭉 올라가다가 `Successfully installed`가 뜨면 설치를 마친 것이랍니다.
`Requirement already satisfied`는 이미 깔려 있다는 뜻이니 안심하시와요. 영어가 길다고 전부 꾸중은 아니랍니다.

### 5-3. 시험 설치 (게임은 건드리지 않는답니다)

실제로 설치하기 전에 문제가 없는지 살피는 단계랍니다. **게임 파일은 하나도 바뀌지 않으니** 마음 놓고 실행하시와요. 급하다고 이 확인부터 건너뛰는 것은 허락하지 않겠사와요.

아래 명령어를 메모장에 복사한 뒤, `"게임 폴더"`와 `"로더 폴더"` 부분을 4번에서 복사해 둔 경로로 **따옴표째** 바꿔 넣으시와요.

```powershell
python install.py --game-root "게임 폴더" --loader-root "로더 폴더" --check
```

바꾸고 나면 대략 이런 모양이 된답니다.

```powershell
python install.py --game-root "C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada" --loader-root "C:\DRTC-Loader\1.MOD LOADER" --check
```

이 한 줄을 통째로 명령창에 붙여넣고 엔터를 누르시와요. 시간이 조금 걸려도 같은 명령을 거듭 넣지 말고 기다리시와요. 재촉한다고 검사가 빨라지는 것은 아니랍니다.

- `{ "mode": "install", ... }` 같은 것이 쭉 뜨면 **성공**이랍니다. 다음 단계로 넘어가시와요
- 빨간 글씨로 `ERROR: ...`가 뜨면 **실패**랍니다. [7번 오류 모음](#7-오류가-뜨면)을 살펴보시와요

### 5-4. 진짜 설치

시험 설치를 무사히 마쳤다면, 방금 쓴 명령어의 **맨 끝 `--check`만 `--apply`로 바꿔** 다시 실행하시와요. 이제야 진짜 설치를 맡겨 드릴 차례랍니다.

```powershell
python install.py --game-root "C:\Program Files (x86)\Steam\steamapps\common\Death Road to Canada" --loader-root "C:\DRTC-Loader\1.MOD LOADER" --apply
```

- 설치 전에 게임 폴더를 통째로 **백업**한답니다. 게임 폴더 옆에 `Death Road to Canada_KO_backup_날짜` 같은 이름으로 생기는 것이와요
- 통째로 복사하므로 **시간이 걸리고 그만큼 용량도 차지한답니다**. 되돌아갈 길까지 챙기는 중이니 조금만 기다려 주시와요
- 끝난 뒤 `ERROR`가 없다면 설치를 마친 것이랍니다

이제 스팀에서 평소처럼 게임을 켜시면 한글로 나온답니다. 여기까지 따라오셨으니 그대도 제법 끈기가 있사와요. 본 영애의 솜씨에 감탄하는 일은 게임을 즐기면서 천천히 하셔도 좋답니다.

백업 위치를 직접 정하고 싶으시다면 `--apply` 앞에 `--backup-root "새 폴더 경로"`를 넣으시와요. 다만 그 폴더는 **아직 존재하지 않는 새 폴더**여야 한답니다.

**백업 폴더는 지우지 마시와요.** 나중에 패치를 지울 때 원래 파일을 꺼내 쓸 곳이랍니다. 설치가 끝났다고 쓸모까지 끝난 줄 아시면 제가 곤란하사옵니다.

## 스팀덱과 리눅스에서 깔기 (실험적)

스팀덱에서는 리눅스판 대신 **윈도우판을 Proton으로** 실행해야 한답니다. 한글을 띄우는 모드 로더가 윈도우 전용이기 때문인 것이와요.
설치 프로그램은 이쪽에서도 검증·백업을 거쳐 설치하도록 만들었고, 리눅스에서 가짜 게임 폴더로 설치부터 삭제까지 시험을 마쳤사와요. 다만 **Proton 위에서 로더가 실제로 돌아 한글이 뜨는지는 아직 충분히 시험하지 못했답니다.** 자신 있게 권해 드리고 싶어도 확인하지 못한 것까지 장담하는 것은 제 자존심이 허락하지 않사와요. 잘 되든 막히든 [Issues](../../issues)에 알려 주시면 제가 다음 확인을 하는 데 큰 도움이 된답니다.

일반 리눅스 PC도 방법은 같답니다. 아래를 따르시되 [일반 리눅스라면](#일반-리눅스라면)에 적힌 차이만 챙기시와요.
리눅스판 게임(네이티브)이나 스팀이 아닌 곳(GOG 등)에서 산 게임은 지원하지 않으니, 시작 전에 꼭 확인하시와요.

스팀덱에서는 모든 작업을 **데스크톱 모드**에서 진행하시와요. 전원 버튼을 길게 누르고 → `데스크톱 모드로 전환`을 고르시와요. 키보드와 마우스를 꽂아 두시면 한결 수월하답니다. 작은 화면과 씨름하는 끈기까지 시험할 생각은 없사와요.

### D-1. 게임을 윈도우판으로 바꾸기

1. 스팀에서 Death Road to Canada를 오른쪽 클릭 → **속성** → **호환성**으로 가시와요
2. **`특정 Steam Play 호환성 도구 강제 사용`을** 체크하고 Proton을 고르시와요. 가장 최신 Proton이면 된답니다
3. 스팀이 윈도우판을 내려받을 때까지 기다리시와요
4. 다 받으면 **속성 → 설치된 파일 → 게임 파일 무결성 검사**를 한 번 해 두시와요

**앞으로도 이 체크는 유지하시와요.** 해제하면 스팀이 리눅스판으로 되돌리면서 패치가 망가진답니다. 리눅스판으로 돌아가고 싶으시다면 [D-6](#d-6-스팀덱리눅스에서-지우기)에 따라 패치부터 지운 다음 체크를 해제하시와요. 순서를 바꾸는 재주는 여기서 부리지 마시와요.

### D-2. 패치와 로더 받기

1. 위 [2번](#2-한글패치-받기)처럼 이 페이지에서 ZIP을 받아, 파일 관리자(Dolphin)에서 오른쪽 클릭 → **압축 풀기**를 하시와요. `~/DRTC-KO` 같은 곳이 좋답니다
2. 위 [3번](#3-모드-로더-받기)처럼 로더 **V202.0**을 받아 `~/DRTC-Loader` 같은 곳에 압축을 풀어 두시와요
   - 압축 파일이면 Dolphin에서 오른쪽 클릭 → **압축 풀기**를 하시거나 Ark로 여시와요
   - 실행형(.exe) 압축이라 풀리지 않는다면 윈도우 PC에서 풀어 `1.MOD LOADER` 폴더만 USB 등으로 옮겨 오셔도 괜찮사와요
   - 이쪽에서도 **`prog_Patch.exe`는 실행하지 마시와요**

### D-3. 경로 확인

- **게임 폴더**: 스팀에서 게임 오른쪽 클릭 → 관리 → 로컬 파일 보기를 누르시와요. 보통 경로는 아래와 같답니다
  - 본체: `~/.local/share/Steam/steamapps/common/Death Road to Canada`
  - SD카드: `/run/media/` 아래의 `steamapps/common/Death Road to Canada`
- **로더 폴더**: `dr2c-gadget.dll`이 바로 보이는 `1.MOD LOADER` 폴더랍니다
- Dolphin에서 폴더를 연 채로 **Ctrl+L**을 누르면 위쪽에 경로가 나오니 복사해 두시와요

### D-4. 터미널 열기와 부품 설치 (처음 한 번만)

1. Dolphin에서 **패치 폴더**를 연 다음 **F4**를 누르면 아래에 터미널이 열린답니다 (또는 빈 곳 오른쪽 클릭 → 터미널 열기)
2. 패치 전용 파이썬 환경을 하나 만들어 쓰겠사와요. 스팀덱의 시스템 영역까지 손댈 필요는 없으니, 아래를 한 줄씩 실행하시와요

```bash
python3 -m venv ~/drtc-venv
~/drtc-venv/bin/python -m pip install -r requirements.txt
```

`Successfully installed`가 뜨면 준비를 마친 것이랍니다. 붙여넣기는 **Ctrl+Shift+V**로 하시와요. 윈도우에서 쓰던 손버릇에 Shift 하나만 더 챙기시와요.

### D-5. 설치

**게임은 완전히 꺼 두시와요.** 경로에 띄어쓰기가 있으니 반드시 따옴표로 감싸시와요. 보기 좋게 정리한다며 따옴표를 빼 버리는 것은 사양하겠사와요.

```bash
~/drtc-venv/bin/python install.py --game-root "$HOME/.local/share/Steam/steamapps/common/Death Road to Canada" --loader-root "$HOME/DRTC-Loader/1.MOD LOADER" --check
```

`{ "mode": "install", ... }`이 뜨면 끝의 `--check`를 `--apply`로 바꿔 다시 돌리시와요. 백업은 윈도우와 똑같이 게임 폴더 옆에 생긴답니다.
설치를 마치면 게임 모드로 돌아가 평소처럼 실행하시와요. 오류가 났다면 [7번 오류 모음](#7-오류가-뜨면)을 살피시와요. 스팀덱에서도 그 안내가 그대로 통한답니다.

### 일반 리눅스라면

- 데스크톱 모드 전환은 필요 없사와요. D-1부터 그대로 하시와요
- **Debian/Ubuntu 계열**은 D-4에서 `venv`가 없다고 나올 수 있사와요. 먼저 `sudo apt install python3-venv`를 하시와요
- **Flatpak 스팀**이라면 게임 폴더가 이곳이랍니다. D-5, D-6의 `--game-root`를 이것으로 바꾸시와요
  - `~/.var/app/com.valvesoftware.Steam/.local/share/Steam/steamapps/common/Death Road to Canada`
- 터미널은 쓰시는 파일 관리자에서 여시거나, 터미널을 켜고 `cd ~/DRTC-KO`로 패치 폴더에 들어가시와요. 명령어는 D-4, D-5와 똑같답니다

### D-6. 스팀덱·리눅스에서 지우기

**Proton 체크를 풀기 전에** 패치 폴더의 터미널에서 지우시와요.

```bash
~/drtc-venv/bin/python uninstall.py --game-root "$HOME/.local/share/Steam/steamapps/common/Death Road to Canada" --check
~/drtc-venv/bin/python uninstall.py --game-root "$HOME/.local/share/Steam/steamapps/common/Death Road to Canada" --apply
```

이미 체크를 풀어 버리셨다는 말이와요?! 그것이 그리도 급하셨사와요? 그러면 리눅스판 파일이 덮어써져서 `uninstall.py`가 안전을 위해 멈춘답니다. 당황해서 다른 파일까지 만지지는 마시와요. 수습할 순서도 제가 적어 두었답니다.

1. 다시 Proton을 강제하고 **게임 파일 무결성 검사**까지 마치시와요. `prog.exe`와 영어 스크립트가 원래대로 돌아온답니다
2. 무결성 검사는 스팀이 모르는 파일까지 지워 주지는 않는답니다. 게임 폴더에 남은 아래 패치 파일을 직접 지우시와요. 목록 밖의 파일까지 쓸어 담는 과감함은 허락하지 않겠사와요
   - `.drtc_ko_install.json` (숨김 파일이라 Dolphin에서 **Ctrl+H**를 눌러야 보인답니다)
   - `dr2c-gadget.dll`, `dr2c-gadget.config`
   - `mods` 폴더 안의 `DRTC_KO`, `dr2c-mod-loader` (그러고 `mods`가 비었다면 `mods`도)
3. 예전 백업 폴더(`Death Road to Canada_KO_backup_날짜`)는 더 쓸 일이 없으니 지우셔도 된답니다
4. 그다음 D-5부터 새로 설치하시와요. 이번에는 순서를 지켜 주실 것으로 믿겠사와요

## 6. 삭제하는 법

영어판으로 돌아가고 싶으시다니 조금은 섭섭한 것이와요. 그렇다고 돌아가는 길을 감춰 둘 만큼 속 좁은 영애는 아니랍니다. **게임을 끄고** 5-1처럼 패치 폴더에서 명령창을 여시와요.
스팀덱이나 리눅스라면 여기 대신 [D-6](#d-6-스팀덱리눅스에서-지우기)을 따르시와요.

먼저 검사부터 하시와요. 이 단계에서는 아무것도 바뀌지 않는답니다.

```powershell
python uninstall.py --game-root "게임 폴더" --check
```

문제가 없다면 진짜로 지우시와요.

```powershell
python uninstall.py --game-root "게임 폴더" --apply
```

- 패치가 바꾼 파일은 백업에서 원래대로 되돌리고, 패치가 추가한 파일만 지운답니다
- 다 끝나도 백업 폴더는 남아 있답니다. 영어로 잘 나오는 것까지 확인한 뒤에 지우시와요. 마지막 확인도 전에 청소부터 서두르지는 마시와요
- 패치 파일을 직접 건드리셨거나 백업이 망가져 있다면 안전을 위해 중간에 멈춘답니다

설치·삭제 중 **Ctrl+C**를 누르면 그때까지 적용한 변경을 되돌린답니다. 파일 잠금 등으로 일부 복구가 실패했다면 **설치 기록과 백업은 그대로 남겨 두시와요.** 놀란 김에 둘 다 지워 버리시면 복구할 길까지 잃게 된답니다.
게임을 끄고 잠금 원인을 해소한 다음, 위의 `uninstall.py --check`와 `--apply`를 차례로 다시 실행하시와요. 남은 패치 파일을 검증해 원래 상태로 복구한답니다. 그대가 직접 수정한 파일은 덮어쓰지 않고 멈추도록 해 두었으니, 복구에 필요한 것부터 차분히 챙기시와요.

| `Loader SHA-256 mismatch or missing file` | 로더 폴더를 잘못 고르셨거나, 버전이 다르거나, 파일이 빠졌거나 바뀐 것이랍니다. `dr2c-gadget.dll`이 **바로** 들어 있는 `1.MOD LOADER` 폴더인지, V202.0을 받은 그대로 두셨는지 3번에서 확인하시와요 |

| `Backup root must be a new, nonexistent folder` | `--backup-root`로 지정한 폴더가 이미 있답니다. 아직 없는 새 폴더 이름으로 바꾸시와요. 다른 파일이 든 곳에 백업까지 밀어 넣게 두지는 않겠사와요 |
| `No Korean patch installation record` (삭제할 때) | 이 게임 폴더에서 설치 기록을 찾지 못했답니다. 다른 폴더를 가리키고 있지는 않은지 경로부터 확인하시와요 |
| `This installer requires Windows or Linux` | 설치 프로그램은 윈도우와 스팀덱·리눅스용이랍니다. 맥까지 맡겨 주시고 싶어도 이번에는 저도 어쩔 도리가 없사와요 |
| `A prog.exe is running ... cannot be verified` (스팀덱·리눅스) | `prog.exe`가 실행 중인데 어느 게임인지 확인할 수 없답니다. Proton에서는 이 게임도 그렇게 보일 때가 있사와요. 짐작만으로 설치를 밀어붙일 수는 없으니, 스팀에서 실행 중인 게임을 모두 끄고 다시 실행하시와요 |

오류에 그대 컴퓨터의 사용자 이름 같은 것이 찍혔다면 그 부분은 꼭 가리시와요. 문제를 살피는 데 그대의 신상까지 필요한 것은 아니랍니다.

## 8. 알려진 문제

- `은(는)`, `이(가)`처럼 조사가 함께 나오는 곳이 있답니다. 저도 눈에 거슬리지만, 캐릭터 이름이 무작위로 들어가는 탓에 이렇게 남겨 둘 수밖에 없었사와요
- 캐릭터 이름과 특성 이름 같은 것은 일부러 영어로 두었사와요. 게임이 이 문자열로 내부 판정을 하는지라, 번역했다가는 게임이 꼬여 버리는 것이와요. 영어가 보인다고 제가 그 줄만 못 본 척한 것은 아니랍니다
- 캐릭터 이름을 한글로 입력하는 것은 아직 제대로 시험하지 못했답니다. 그 부분까지 자신 있게 권해 드리지 못하는 것은 저도 아쉽사와요
- 처음부터 엔딩까지 한 판을 모두 확인한 것은 아니랍니다. 빈틈없이 내놓고 싶었는데, 이 대목은 저도 면목이 없사와요. 이상한 곳이 보이면 제보해 주시와요. 제 눈을 빠져나간 문장을 그대로 둘 생각은 없답니다

오역이나 어색한 문장은 [Issues](../../issues)에 올려 주시와요. **어느 장면(이벤트)에서 나왔는지**도 함께 적어 주시면 찾기가 훨씬 수월하답니다. 칭찬만 받겠다고 제보 창을 열어 둔 것은 아니니, 발견하셨다면 사양 말고 알려 주시와요.

### 어디에도 올려서는 아니 되는 것

- 게임 파일, 백업 폴더, 모드 로더 배포본은 올리지 마시와요. 저작권이 걸려 있으니, 제보를 위해서라도 예외로 삼을 수는 없답니다
- 설치 기록 파일(`.drtc_ko_install.json`)이나 백업 안의 기록 파일도 올리지 마시와요. 그대 컴퓨터의 폴더 경로가 고스란히 담겨 있답니다

### 번역 파일

- `translations/001.po` ~ `033.po`가 대사, `native-ko.po`가 UI 번역이랍니다
- `msgctxt`는 게임 안의 파일 경로랍니다
- 비어 있는 번역과 fuzzy는 영어로 나오고, `<EMPTY>`는 빈 문자열로 바뀐답니다
- 게임이 비교용으로 쓰는 문자열(캐릭터 이름, 특성 이름 등)과 native UI 키는 일부러 영어로 두었사와요
- 빌드할 때 자리표시자, 제어문자, 줄바꿈, 조사 조각, 폰트에 없는 글자까지 빠짐없이 검사한답니다

번역을 더 좋게 다듬은 PR이라면 언제든 환영이랍니다. 본 영애의 문장에 손댈 배짱이 있으시다면, 무엇을 왜 고쳤는지도 함께 적어 주시와요.

### 도구 회귀 테스트

필요한 부품을 설치한 뒤 저장소 폴더에서 실행하시와요.

```powershell
python -m unittest discover -s tests -v
```

게임 파일 없이 임시 파일로 설치·삭제 중단, 불완전 롤백 후 재시도, 외부 수정 보호, 비교 문자열 분류, 그리고 가짜 `/proc`을 이용한 Proton 실행 감지까지 검사한답니다. 다만 실제 게임 실행과 Windows 프로세스 검사까지 대신해 주지는 않으니, 그 둘은 따로 확인해야 마땅하답니다.

### 설치 없이 한글 모드만 만들어 보기

출력할 새 폴더를 지정해 실행하시와요. 게임/로더/패치 폴더와 겹치는 것은 허락하지 않겠사와요. 만든 결과물과 재료를 한데 섞어 두면 그대도 곤란해진답니다.

```powershell
python build_ko.py --game-root "<게임 폴더>" --loader-root "<로더 폴더>" --output "<생성 폴더>"
```

### 설치 방식

- PC에 있는 영어 `.df` 스크립트의 해시를 검증하고, 그것으로 한글판을 그 자리에서 생성한답니다
- 원래 `deathforth/` 파일은 그대로 두고, `mods/DRTC_KO/`를 위에 덮어씌우는 방식이랍니다
- 로더 배포본에서는 검증된 파일 8개만 읽으며, 일본어 대사나 `prog_Patch.exe`는 건드리지 않는답니다. `prog.exe` 패치는 설치 프로그램이 직접 맡는 것이와요 (pefile은 `vendor/`에 들어 있사와요)
- `--check`는 임시 폴더에서 빌드와 설치 검증만 하고, `--apply`는 게임 폴더 전체를 백업하고 해시를 확인한 다음 설치한답니다
- 로더 원본 프로젝트는 [sevenshape/dr2c-mod-loader](https://github.com/sevenshape/dr2c-mod-loader)랍니다. 옛날 `SDL2_mixer.dll` 프록시 방식과는 호환되지 않으니, 익숙하다고 예전 방식을 섞지는 마시와요

### 폰트

`fonts/hangul_12x12.png`는 Galmuri11로 만든 한글 전용 투명 오버레이랍니다.
설치할 때 로더 폰트 아틀라스의 한글 칸(U+AC00–D7A3, U+3131–318E)에만 합쳐지고, 다른 글자와 아이콘은 그대로 남는답니다. 12×12 비트맵 폰트로 완성형 한글과 호환 자모를 모두 표시하는 것이와요. 한글을 넣겠다고 다른 글자와 아이콘까지 밀어내는 무례는 부리지 않았사와요. 다시 만들고 싶으시다면 아래처럼 실행하시와요.

```powershell
python make_hangul_atlas.py --bdf fonts/Galmuri11.bdf --output "<새 오버레이 PNG>"
```

생성된 `.df`, 게임 실행 파일, 백업, 로더 배포본은 공개 저장소에 올리지 마시와요.
